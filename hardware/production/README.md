# Fertigungsdaten Rev A (JLCPCB)

* `RX-Board_RevA_BOM_JLCPCB.csv`: Stückliste mit LCSC-Nummern.
* `RX-Board_RevA_CPL_JLCPCB.csv`: Bestückungsdatei (Position aus KiCad, Drehung für JLCPCB korrigiert).

Drehkorrekturen gegenüber KiCad (in der JLCPCB-Vorschau geprüft): U1 = 90, D1 = 180, D2 = 180. Alle anderen Bauteile 0.

Die Gerber- und Bohrdateien werden in KiCad erzeugt (Gerber getrennt nach PTH und NPTH) und hier nicht abgelegt.
